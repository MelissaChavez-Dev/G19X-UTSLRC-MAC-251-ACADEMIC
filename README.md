# Dashboard Ejecutivo de Salud Organizacional

Proyecto individual desarrollado como parte del periodo de estadía en **PluriOne S.A. de C.V. — Develop Talent & Technology**, dentro del programa de capacitación especializada **TODO Academy**.

## Descripción

Aplicación web que consolida indicadores de salud organizacional (bienestar, ausentismo, rotación, clima laboral, desempeño y factores psicosociales) dispersos en distintas fuentes, presentándolos mediante tableros ejecutivos interactivos con apoyo de inteligencia artificial para la generación de alertas e interpretación de tendencias.

## Autora

Melissa Alejandra Chávez — TSU en Desarrollo de Software Multiplataforma, Universidad Tecnológica de San Luis Río Colorado (UTSLRC).

## Stack tecnológico

- **Frontend:** React.js (Vite) + Tailwind CSS + Framer Motion
- **Visualización:** Recharts / Tremor
- **Backend:** Firebase Authentication, Firestore
- **Funciones en la nube:** Cloud Functions (Python 3.8+)
- **Inteligencia artificial:** Gemini API (gemini-3.8-flash)
- **Control de versiones:** Git / GitHub
- **Metodología de trabajo:** Scrum
